# Chess (data generation + benchmarking)

PSF itself is chess-agnostic. Chess support in this repo is provided as a standalone dataset generator plus a few example systems under `systems/`.

Benchmark scenario format is documented in `docs/benchmarking.md`.

## Install chess extras

Chess utilities require `python-chess`:

```bash
pip install -e ".[chess]"
```

## Generate benchmark datasets

All datasets are generated by `chess_data.py` (repo root). Key knobs are:

- `--count`: how many scenarios to generate
- `--plies`: how many random legal plies to play before sampling a position
- `--seed`: deterministic RNG seed

### Move validation (legal check)

Generates `psf_benchmark_scenario_v1` scenarios with:

- `input`: `position_fen`, `candidate_move`, `move_notation` (+ `board_context`)
- `expected`: string (`true` for legal, `false` for illegal)

SAN:

```bash
python chess_data.py --task legal_check_san --out-dir examples/input/chess/legal_check_san --count 200 --plies 8 --seed 1 --illegal-ratio 0.5 --overwrite
```

UCI:

```bash
python chess_data.py --task legal_check_uci --out-dir examples/input/chess/legal_check_uci --count 200 --plies 8 --seed 1 --illegal-ratio 0.5 --overwrite
```

### Move generation

Generates `psf_benchmark_scenario_v1` scenarios with:

- `input`: `position_fen`, `move_notation`, `illegal_moves` (optional), `attempt` (+ `board_context`)
- `expected`: list of legal moves in the requested notation

SAN:

```bash
python chess_data.py --task move_generation_san --out-dir examples/input/chess/move_generation_san --count 200 --plies 8 --seed 1 --overwrite
```

UCI:

```bash
python chess_data.py --task move_generation_uci --out-dir examples/input/chess/move_generation_uci --count 200 --plies 8 --seed 1 --overwrite
```

To test “validated/retry” generators that must avoid prior attempts, you can pre-populate `illegal_moves`:

```bash
python chess_data.py --task move_generation_uci --out-dir examples/input/chess/move_generation_uci_forbidden --count 200 --plies 8 --seed 1 --forbidden-moves-per-scenario 3 --overwrite
```

## Benchmark with PSF

### Legal check systems (`expected` vs `answer`)

SAN:

```bash
psf benchmark --system systems/chess_san_legal_check_yn_system.yaml --inputs-dir examples/input/chess/legal_check_san --iterations 20
```

Compare two SAN legality systems:

```bash
psf benchmark --system systems/chess_san_legal_check_yn_system.yaml --system systems/<your_second_san_validator>.yaml --inputs-dir examples/input/chess/legal_check_san --iterations 20
```

Artifacts are written under `runs/benchmarks/<benchmark_id>/` (see `suite_summary.json`).

UCI:

```bash
psf benchmark --system systems/chess_uci_legal_check_yn_system.yaml --inputs-dir examples/input/chess/legal_check_uci --iterations 20
```

### Move generation systems (`expected` vs `answer`)

SAN generator:

```bash
psf benchmark --system systems/chess_san_move_generator_system.yaml --inputs-dir examples/input/chess/move_generation_san --iterations 20
```

UCI generator:

```bash
psf benchmark --system systems/chess_uci_move_generator_system.yaml --inputs-dir examples/input/chess/move_generation_uci --iterations 20
```
